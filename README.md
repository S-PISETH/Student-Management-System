# 🎓 Student Management System

A desktop-based **Student Management System** built with **Java Swing** for the graphical user interface and **Microsoft SQL Server** for reliable, relational data storage. This application is designed to simplify administrative tasks such as tracking student records, managing courses, and handling enrollments.

---

## 🚀 Features

- **User Authentication:** Secure login system for administrators or staff.
- **Student Record Management:** Add, update, view, and delete student profiles (Name, DOB, Gender, Contact Info, Address).
- **Course & Enrollment Management:** Assign students to specific courses or classes.
- **Database Integration:** Real-time data persistence using Microsoft SQL Server.
- **Intuitive GUI:** User-friendly desktop interface built using Java Swing components (JTables, JForms, etc.).

---

## 🛠️ Tech Stack

- **Programming Language:** Java (JDK 8 or higher)
- **GUI Framework:** Java Swing, AWT
- **Database:** Microsoft SQL Server
- **Database Connectivity:** JDBC Driver (`sqljdbc4.jar` or mssql-jdbc)
- **IDE Recommended:**  NetBeans
